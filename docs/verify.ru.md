# Как проверить установщик evolite

English: [verify.md](verify.md).

Установщики evolite **не подписаны сертификатом разработчика**. Windows SmartScreen и macOS Gatekeeper предупреждают о них, и по предупреждению настоящий установщик от поддельного не отличить. Поэтому к каждому выпуску прилагаются:

- **`SHA256SUMS`**: SHA-256 каждого установщика.
- **`SHA256SUMS.minisig`**: подпись [minisign](https://jedisct1.github.io/minisign/) этого списка, сделанная без сети ключом выпусков evolite.

Проверьте оба, прежде чем устанавливать. Это несколько минут, один раз на выпуск.

## 1. Скачайте

Со страницы выпуска (`https://github.com/Ulput/evolite/releases`) скачайте в одну папку:

- свой установщик, например `evolite-setup-windows-x86_64.exe`;
- `SHA256SUMS`;
- `SHA256SUMS.minisig`.

## 2. Возьмите открытый ключ и сверьте его в двух местах

Открытые ключи выпусков evolite (годится подпись любым из них):

```
main:   <published with the first signed release>
backup: <published with the first signed release>
```

Сверьте ключ, которым проверяете, хотя бы с **двумя** из этих мест:

- эта страница в репозитории;
- `README.md` репозитория;
- установленный evolite: **Настройки › О программе** показывает оба ключа;
- <место вне GitHub, будет названо с первым подписанным выпуском>.

Если они различаются — остановитесь, не устанавливайте.

## 3. Проверьте подпись `SHA256SUMS`

Установите minisign из официального источника, `https://github.com/jedisct1/minisign/releases`. Скачанный minisign проверьте по суммам, опубликованным там же.

```
minisign -Vm SHA256SUMS -P <ключ main>
```

Должно быть `Signature and comment signature verified`. Если не так — попробуйте ключ backup. Если не подходит ни один — остановитесь.

## 4. Проверьте сумму установщика

Сравните SHA-256 своего установщика с его строкой в `SHA256SUMS`.

- **Windows (PowerShell):** `Get-FileHash .\evolite-setup-windows-x86_64.exe -Algorithm SHA256` или `certutil -hashfile evolite-setup-windows-x86_64.exe SHA256`
- **macOS:** `shasum -a 256 evolite-setup-macos-*.dmg`
- **Linux:** `sha256sum -c --ignore-missing SHA256SUMS`

Сумма должна совпасть полностью, до последнего знака.

## 5. Если что-то не совпало

Не устанавливайте и нигде не вводите фразу восстановления. Удалите скачанные файлы и сообщите об этом (<куда — будет названо с первым подписанным выпуском>).

## 6. Предупреждение системы, когда проверка пройдена

- **Windows:** SmartScreen пишет «Система Windows защитила ваш компьютер». Выберите **Подробнее › Выполнить в любом случае**.
- **macOS:** правый щелчок по установщику › **Открыть**, затем ещё раз **Открыть**.

Предупреждение — потому что установщик не подписан сертификатом; что он от evolite, говорит проверка выше.

## В приложении

Раз в день evolite проверяет, нет ли новой версии, если включено **Настройки › Приватность › Проверять новую версию**. Он верит только сообщению, подписанному ключами выше. Сам он ничего не скачивает и не устанавливает: только даёт ссылку сюда и на страницу выпуска.
